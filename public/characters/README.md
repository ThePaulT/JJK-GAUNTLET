# Character art

Optional, and empty on purpose.

Drop an image named after a character's id and the app uses it everywhere that
character appears — draft cards, the versus bar, the MVP line. Anything missing
falls back to the generated stat sigil, so you can add art one character at a
time and nothing breaks in between.

- Square, around 256x256, looks best.
- `.webp` is tried first, then `.png`, then `.jpg`.
- No restart needed in production; it is just a static file.

**Nothing ships here because Jujutsu Kaisen artwork is copyrighted and this site
is public. Only add images you have the right to use.**
