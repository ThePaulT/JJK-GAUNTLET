# Character art

Optional. Drop an image named after a character's id — `toji.webp`,
`gojo.png`, `yuji.jpg` — and the app uses it wherever that character appears.
Anything missing falls back to the generated stat sigil, so you can add art one
character at a time.

Square images work best, around 256x256. `.webp` is tried first, then `.png`,
then `.jpg`.

Nothing is shipped here on purpose: Jujutsu Kaisen artwork is copyrighted, and
this project is public. Only add images you have the right to use.
